Mathematical Freshness Scoring

Algorithmic Rigor
  • 1. Volatility Classifier (RE2): Identifies temporal cues (realtime, high, medium, low, static) and dynamically controls cache TTLs.
  • 2. Domain Half-Life Staleness Prior (P):
    P = 1 - 0.5 ^ (Days_Elapsed / Category_HalfLife)
    Event status (14 days) decays faster than leadership (365 days) or software versions (90 days).
  • 3. Multi-Factor Evidence Scoring (C):
    C = clamp(0.5 * Authority + 0.3 * Recency + 0.2 * JudgeConfidence, 0, 1)
  • 4. Non-Binary Freshness Output (0–100): Fresh (≥ 75, Green), Aging (45–74, Amber), Stale (< 45, Rose).
