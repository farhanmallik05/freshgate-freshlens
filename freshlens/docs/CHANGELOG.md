# FreshLens Changelog

## [1.0.0] - 2026-11-02
### Added
- Initial extension scaffolding with WXT, React 18, and Tailwind.
- Canonical contract synchronization with FreshGate Engine schemas.
- Background service worker with session LRU caching and demo fixtures.
- Content script adapters for ChatGPT, Claude, and local `/demo-chat`.
- CSS Custom Highlight API integration with accessible patterns (solid/dashed/wavy).
- Isolated Shadow DOM overlay UI (`#freshlens-root`) with expandable claim drawer.
- Action triggers: "Fix with fresh context", "Copy corrected answer", "Copy report".
- Landing page and interactive playground in `site/`.
